# When Math Journals Pause Submissions

Slides for a talk by Jun Yin (UCLA), November 2026, given to students in mathematics.

What happens to mathematics journals, and to the people who do mathematics, when proofs become cheap? The talk opens with a journal that pauses submissions and closes, a few eras later, with the journal open again.

## Files

- [`When-Math-Journals-Pause-Submissions.pdf`](When-Math-Journals-Pause-Submissions.pdf): the slides, 37 pages.
- [`speaker-notes.md`](speaker-notes.md): the speaker notes, slide by slide. The slides carry very few words on purpose; the argument is in the notes.
